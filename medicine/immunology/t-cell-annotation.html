T细胞亚群与注释

本页整理常见T细胞状态、功能亚群及参考标志物，重点区分谱系身份、分化状态、即时活化和功能状态。

注释原则：marker不是定义本身。单个基因或蛋白通常不足以判定亚群；应结合多基因模块、蛋白流式、组织来源、刺激状态、物种差异和功能实验。转录组中的RNA表达也不等同于表面蛋白表达。

一、总体结构

T cell
├── TCRαβ T
│   ├── CD4+ T：helper / regulatory / cytotoxic
│   └── CD8+ T：naive / effector / memory / exhausted
└── TCRγδ T
    └── innate-like features are common

Innate-like T subsets: MAIT, iNKT（具有特殊受体与抗原识别体系）

二、基础状态

Naive T cell（初始T细胞）

已离开胸腺、尚未经历同源抗原刺激的成熟T细胞。人类常用参考表型：

CCR7hi, CD45RA+, CD45RO−, CD95−；常见CD27+, CD28+, CD127+。

短时TCR刺激后通常不会像已分化效应细胞那样迅速大量产生IFN-γ、IL-4或IL-5。

Effector T cell（效应T细胞）

描述具有即时效应功能或表达效应分子的T细胞，不必然意味着终末分化。参考效应分子包括GZMB、PRF1、细胞因子及CD40L；需结合细胞毒性、增殖潜能和记忆形成能力判断。

Activated T cell（活化T细胞）

CD69+, CD25hi, KLF2low；常伴Ki67+, HLA-DR+, CD38hi或效应分子表达。

CD69、CD25等多为动态标志，活化时间窗和刺激类型会影响表达。

Memory T cell（记忆T细胞）

常见CD11ahi、CD95+、CD58+、CD49d+。

人类记忆T细胞与其他抗原经历细胞存在表型重叠，不能依靠单一marker区分。

Anergic T cell（无反应T细胞）

在特定抗原刺激背景下形成的低反应状态，缺乏通用且可靠的单一表面marker。需要通过再刺激后的增殖和细胞因子功能实验确认。

Virtual memory T cell（虚拟记忆T细胞）

未经历经典同源抗原致敏、却呈现部分记忆样表型的T细胞。人类定义和标志物仍不统一，不能直接套用小鼠标准。

三、CD8+ T细胞分化与记忆

SLEC / TE（短寿命效应/终末效应细胞）

参考人类表型：CCR7−, CD45RA+, KLRG1+, TCF1low, T-bethi, CX3CR1+, CD127low, CD27−, CD57+。

高度分化、细胞毒活性较强，群体层面通常记忆潜能较低；但这些marker不能保证细胞必然短寿命。

MPEC / MP（记忆前体效应细胞）

指活化后仍保留形成长期记忆细胞潜能的效应细胞。不同感染模型、组织和物种的代理marker差异较大，不存在普遍适用的单一组合。

EEC（早期效应细胞）

可见KLRG1low, CD127−, CXCR3+, T-bet+, TCF1low，并可产生IFN-γ和TNF。

LLEC（长寿命效应细胞）

部分研究中表现为KLRG1hi, CD127int, CX3CR1hi, GZMBhi。定义依赖具体研究模型。

TCM / TEM / TEMRA

  • TCM（中央记忆）：CCR7+, CD62L+, CD45RO+, CD45RA−；具有较强增殖和再分化潜能。
  • TEM（效应记忆）：CCR7−, CD45RA−，通常CD62L低/阴性；迁移与效应功能异质。
  • TEMRA：CCR7−, CD45RA+, often CD27−, CX3CR1hi, CD57+；常具快速细胞毒反应倾向。该命名主要用于人类。

TRM（组织驻留记忆T细胞）

常见KLF2low, CD69+, CD62L−, CCR7−；部分组织/亚群表达CD103、CD49a、CD101、CXCR6。

组织驻留是迁移与定位属性，需结合组织取样、血管内标记、组织定位或TCR克隆比较等证据，不能仅凭CD69判断。

TPM / TSCM / ExTRM

  • TPM：外周组织与血液间循环的记忆T细胞概念，表型尚无统一定义。
  • TSCM：干细胞样记忆T细胞，常见CD95+, CCR7+, CD27+, CD28+, CD45RA+, Eomes−，兼具自我更新与分化潜能。
  • ExTRM：由TRM样状态重新进入循环的细胞，可能保留组织驻留相关表观遗传印记，定义仍在发展。

四、CD4+ T细胞功能亚群

TH1

T-bet+, CXCR3+；刺激后IFN-γ+。典型功能是细胞内病原体免疫与细胞免疫。

TH2

GATA3+, CCR4+, CRTH2+；刺激后IL-4、IL-5和/或IL-13+。参与抗蠕虫免疫和过敏反应。

TH9

PU.1、IRF4、BATF相关；刺激后IL-9+，部分组织环境可见PPARγ。

TH17

RORγt+, CCR6+；刺激后IL-17A/F+，参与黏膜防御及炎症。

TFH / GC-TFH

CXCR5+, BCL6+。帮助B细胞活化、类别转换、亲和力成熟和记忆形成。GC-TFH位于生发中心；具体组织定位需结合组织学证据。

Treg（调节性T细胞）

FOXP3+, CD25hi, CD127low, CTLA4+, GITR+。通过细胞接触、抑制性细胞因子及代谢竞争等机制维持免疫耐受。

  • tTreg：胸腺来源；pTreg：外周诱导；在人类中两者难以仅凭常规表型区分。
  • eTreg：活化/效应型Treg，常见FOXP3hi、CD45RO+、CCR8hi、ICOShi、IRF4+（组织依赖）。
  • iTreg：体外诱导产生的Treg。
  • TFR：滤泡调节性T细胞，常见CXCR5+、FOXP3+、GITR+，可表达IL-10。

CD4+ CTL

具细胞毒能力的CD4+ T细胞，可表达GZMB、PRF1；常见CCR7−、CD27−。需用杀伤实验验证其细胞毒功能。

五、T细胞耗竭

TPEX（前体/祖细胞样耗竭T细胞）

PD-1+, TOX+, TCF1+, BCL6+, SLAMF6+, CXCR3+, LEF1+, CD28+；常为TIM-3−、CD39−、GZMB低。

在慢性抗原刺激下维持耗竭谱系，具有自我更新能力，可产生过渡性耗竭细胞；是PD-1阻断后扩增的重要细胞来源之一。

TEX-int / effector-like TEX

PD-1+, TOX+, TIM-3+, T-bet+, GZMB+, PRF1+, IFN-γ+；常TCF1−、SLAMF6低。

具有一定效应功能，但处于持续刺激驱动的耗竭分化轨迹中。

TEX-term（终末耗竭）

PD-1+, TOX+, TIM-3+, GZMB+, CD39+, 2B4+, CD101+；TCF1−、SLAMF6−。

增殖能力和功能可塑性通常较低，但仍可能保留部分细胞毒或趋化因子表达。耗竭不是简单的“活化更强”，也不能只凭PD-1判定。

六、Innate-like与非典型T细胞

MAIT

表达相对受限的TCR，识别由非多态性MR1呈递的微生物核黄素代谢物。确认方法包括MR1-5-OP-RU tetramer；外周血常用CD3、CD161和Vα7.2组合初筛。

iNKT

识别CD1d呈递的脂质抗原，TCR库受限。可用CD1d-αGalCer tetramer，或结合Vα24-Jα18/6B11等标志。

γδ T

由TCRγδ定义。人外周血常见Vγ9Vδ2群体；Vδ2−群体中常见Vδ1+细胞。不同组织的γδ T细胞生态差异很大。

其他非典型群体

  • CD8αα+ TCRαβ T：表达CD8αα同源二聚体，区别于常见CD8αβ。
  • DN T：TCR+、CD3+、CD4−、CD8−，需排除双细胞和低质量细胞。
  • 胸腺外DP T：同时表达CD4和CD8，具有异质性，CD8可为αα或αβ。

单细胞注释实践提示

  • 先区分T/NK，再区分TCRαβ、γδ及MAIT/NKT；避免把NKG7/GNLY表达直接等同NK。
  • 初始/记忆：CCR7、IL7R、LTB、MAL、TCF7、LEF1等组合；细胞毒：NKG7、CCL5、PRF1、GZMB；耗竭：PDCD1、TOX、TIGIT、LAG3、HAVCR2、ENTPD1等组合。
  • PDCD1、CTLA4、TIGIT等也可在近期活化细胞中升高；耗竭判定应综合转录程序、持续抗原背景及功能证据。
  • 人/鼠marker、外周血/肿瘤/组织marker不能无条件互换；酶消化可能影响部分表面分子检测。
